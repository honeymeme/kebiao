# 排空课表工具

给团委 / 系办用的排班工具：把各部门课表汇总成空课表，再按空课表排出每周系办值班表。

- 线上地址：https://paiokebiao.onrender.com
- 门面页（带唤醒提示）：https://honeymeme.github.io/kebiao/

## 两种上传方式

**① 课表 PDF 压缩包**（出空课表 + 值班表）

压缩包按部门分文件夹，例如：

```
办公室课表/
  办公室 张三 智能制造261 13000000000.pdf
  部长/
    办公室 李四 机器人252 13900000000.pdf
```

- 文件名格式：**部门 姓名 班级 联系方式**（顺序可乱，程序按内容识别）
- 部长放 `部长/` 子文件夹，或文件名里带"部长"标记
- 支持两种课表版式（列=星期 / 行=星期）

**② 已经做好的空课表**（只出值班表）

直接选 `XX部门空课表.xlsx`，可一次选多个部门。程序读表格里的「姓名（周段）」和底部信息收集表，
红字视为部长。

## 规则

| 项目 | 规则 |
|---|---|
| 周次 | 每次运行都要手选，不记忆；超出范围的周次忽略 |
| 单双周 | 不区分，整段算有课 |
| 空课表 | 表头「XX部门空课表」；姓名逐行居中；部长红字；底部信息表全员列出、部长放最后并标红 |
| 值班表 | 每周一张「第X周系办值班表」；每格 2 人 `姓名/电话` 逐行；只排周一到周五 |
| 选人顺序 | ①次数少的优先 ②次数相同时按部门顺序：办公室 → 科协 → 青协 → 生活部 → 文体部 → 宣传部 → 心协 → 学习部 → 组织部 |
| 部长 | 干事优先；只有当这格没有干事、或某个干事次数已超平均 2 次以上时才排部长 |
| 排不满 | 格子留空，并在「备注信息」里写明哪一格、缺几个人 |

## 技术结构

```
app/
  server.py      HTTP 服务（标准库 http.server，无需框架）
  core.py        PDF 课表解析 + 空课表生成
  pipeline.py    整体流程、选人算法、值班表生成
  sheets.py      读取"已做好的空课表"（第二种通道）
  static/        前端页面（单文件）
  空课表模板.xlsx / 值班表模板.xlsx
```

- 上传：`/api/upload`（多文件累加）、`/api/check`（统一解析一次）、`/api/generate`
- 解析结果在内存缓存，生成时不再重复解析
- 临时文件写在 `JOBS_DIR`（默认 ./jobs，Render 上是 /tmp/jobs）

## 部署 / 更新

1. 改完代码 push 到 GitHub 仓库 `honeymeme/kebiao`
2. Render 自动重新构建（1–2 分钟）
3. 门面页在 `docs/`，由 GitHub Pages 托管（Settings → Pages → main /docs）

> Render 免费版：闲置 15 分钟休眠，首次访问要等 30–60 秒；9 个部门 122 人时，
> 上传约 5 秒、解析检查约 100 秒、生成约 10 秒。
